# Juego de comportamiento - Normal Superior de Convención

Este proyecto es un juego escolar diseñado para que el profesor registre a los estudiantes y lleve el control de sus vidas durante la clase.

## Funcionalidades

- Registrar nombres de estudiantes
- Buscar estudiantes por nombre
- Cada estudiante empieza con 10 vidas
- Si se porta mal, pierde 1 vida
- Si se comporta bien, gana 1 vida
- Guardado automático en el navegador con `localStorage`
- Carga y reinicio de sesión
- Diseño temático con colores azul, blanco y amarillo

## Cómo usarlo

1. Abre el archivo `index.html` en tu navegador.
2. Escribe los nombres de los estudiantes, uno por línea o separados por coma.
3. Presiona `Iniciar juego`.
4. Selecciona un estudiante.
5. Usa los botones para registrar comportamiento bueno o malo.

## Ejecutar localmente

Puedes usar un servidor local con Python:

```bash
python -m http.server 8000
```

Luego abre esta URL:

```text
http://localhost:8000
```
